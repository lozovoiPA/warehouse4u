## Описание
Warehouse4u (ВашСклад) - веб-приложение управления складом на Node.js (Express.js).
В качестве БД используется PostgreSQL.
Приложение позволяет создавать и изменять товары, точки (склады), создавать перемещения товаров между складами.

## Инструкция по запуску
1. Склонируйте репозиторий с помощью команды</br>
  `git clone https://github.com/lozovoiPA/warehouse4u.git`
2. Репозиторий содержит DOCKERFILE сборки образа приложения и docker-compose.yaml конфигурации сервисов приложения и БД.</br>
  Для сборки и запуска контейнеров достаточно использовать `docker compose up [-d]`
3. Для конфигурации используется файл .env. Укажите следующие константы:
      - PORT: внешний порт приложения
      - DB_PORT: внешний порт БД
      - NODE_ENV: окружение Node.js
      - DB_HOST: хост БД
      - DB_NAME: название БД
      - DB_USER: имя пользователя
      - DB_PASS: пароль пользователя
4. БД может быть заполнена тестовыми данными из скрипта initdb/testdata.sql.
   При отсутствии этой необходимости файл нужно убрать из папки.
5. Для быстрого тестирования функциональности API приложения используйте testapi.sh:
   `chmod +x testapi.sh`
   `./testapi.sh`

## API
Товары (Products)</br>
─────────────────</br>
GET    /api/products                    — Получить список всех товаров</br>
POST   /api/products                    — Создать новый товар</br>
GET    /api/products/categories         — Получить список категорий товаров</br>
GET    /api/products/units              — Получить список единиц измерения</br>
PUT    /api/products/{id}               — Обновить товар по идентификатору</br>
</br>
СКЛАДЫ (Warehouses)</br>
───────────────────</br>
GET    /api/warehouses                  — Получить список всех складов</br>
POST   /api/warehouses                  — Создать новый склад</br>
PUT    /api/warehouses/{id}             — Обновить склад по идентификатору</br>

ОСТАТКИ НА СКЛАДАХ (Stock Items)</br>
────────────────────────────────</br>
GET    /api/warehouses/{id}/stock       — Получить остатки товаров на складе</br>
POST   /api/warehouses/{id}/stock       — Добавить остаток товара на склад</br>
</br>
ДВИЖЕНИЯ ТОВАРОВ (Movements)</br>
────────────────────────────</br>
GET    /api/warehouses/{id}/movements   — Получить движения по складу (входящие и исходящие)</br>
POST   /api/movements                   — Создать движение товара между складами</br>
</br>
ОТЧЁТЫ (Reports)</br>
────────────────</br>
POST   /api/reports/stock               — Сгенерировать отчёт по остаткам (XLSX)</br>
